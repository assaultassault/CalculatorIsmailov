# CalculatorIsmailov 🧮

Настольное приложение «Калькулятор», разработанное в рамках практической работы №2 по дисциплине «Поддержка и тестирование программных модулей».

## 🛠 Стек технологий
* **Платформа:** .NET 8 (WPF)
* **Язык программирования:** C#
* **Архитектура:** MVVM (Model-View-ViewModel)
* **Тестирование:** MSTest

## 📂 Структура проекта
* **IsmailovCalculator** — графический пользовательский интерфейс (WPF).
* **IsmailovCalculatorLib** — библиотека классов, содержащая алгоритм вычисления выражений (Shunting-yard) и логику персистентности.
* **IsmailovCalculatorTests** — проект с модульными тестами для проверки корректности вычислений.

## 🚀 Как запустить
1. Клонируйте репозиторий или скачайте архив проекта.
2. Откройте файл решения `IsmailovCalculator.sln` в **Visual Studio 2022**.
3. Соберите проект и запустите приложение (`F5`).
